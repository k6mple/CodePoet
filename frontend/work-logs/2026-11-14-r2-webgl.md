## 接手者需要知道的变化

- 新增 `frontend/src/renderers/webgl/renderer.ts` 与 `geometry.ts`，版本常量 **`codepoet-webgl-1.0.0`**。使用真实 WebGL context/shader/buffer/draw，不依赖 Canvas 2D 冒充；填充用耳切三角化（支持凹多边形），描边用 butt 端帽 + miter join（超过 Canvas 默认 miterLimit 10 时 bevel），按 IR 数组画序逐节点先填充后描边。
- `sampleScene` 的世界坐标、祖先 opacity 乘积、viewport 裁剪、圆 64 段、polyline 不闭合等语义保持不变；WebGL 只负责把已采样几何栅格化。
- 透明处理：WebGL canvas 声明 premultiplied alpha，片元输出 `rgb * a`，混合用 `ONE, ONE_MINUS_SRC_ALPHA`；不透明背景与透明背景都按 Canvas source-over 语义处理。同一节点的描边环带共享边，避免半透明 join 被重复混合。`toPNG` 通过 2D canvas 复制 WebGL canvas，保持 viewport 尺寸、PNG ≤5MiB。
- 已接入 `registry.hasBrowserRenderer/rendererVersion/create`、`exportBackendFrame`、`CanvasPreview`（WebglFrame）、`FixtureViewer`、`Creator` 能力判断/后端选择、模板/检索/审核/作品等 `preferredBrowserBackend` 调用点。`Creator` 的 WebGL 选项只有在后端 capability 声明 `available` 且 `rendererVersion=codepoet-webgl-1.0.0` 时才可用；默认仍只开 Canvas。
- `#23` 两个前端 P3 已修：draft 预览切换后端不再丢 `restoredTemplate`；模板内联预览/链接统一用 `preferredBrowserBackend`，不再直接取 `supportedBackends[0]`。

## 后端必须完成的注册与验收（本 PR 未改 backend）

1. `backend/app/engine/capabilities.py` 的 `RENDERER_VERSIONS` 增加 `'webgl': 'codepoet-webgl-1.0.0'`；默认启用集合仍只含 `canvas2d`。
2. `backend/app/api/engine.py` 的 WebGL capability 条目按注册/启用状态返回：`available`、`rendererVersion`、`executionModes=['browser_upload']`、`nodeTypes`/`shaderRefs=['flat']`/`animationProperties` 与 Canvas/CSS 对齐，`maxFrames=3`；未注册时保留 `available=false` 和明确 reason。
3. 候选环境用 `CODEPOET_ENABLED_BACKENDS=canvas2d,css,webgl` 显式开启；不要因枚举存在自动开启，也不要在目标环境未验收前默认开放。
4. 模板版本 `supportedBackends` 接受 `webgl`，并走正常模板审核；不要回写已发布版本，克隆新版本再审核。当前 `shared/demo/templates/*.json` 只声明 canvas2d，端到端 WebGL 演示需要一个新版本或新模板。
5. `POST /generations`、`POST /render-jobs`、`POST /work-versions/{id}/reproduce` 的 backend/version 校验必须与前端 `codepoet-webgl-1.0.0` 一致；迁移 `012_browser_render_backends.sql` 已允许 webgl，预计不需要新迁移，但需在目标库确认。
6. 后端验收（真实 API/UI）：WebGL 生成 → 渲染任务 → 浏览器上传 PNG → 保存作品 → 刷新重开 → 按原版本复现；静态和 4 秒动画 0/2000/4000 三时刻；服务端下载内容 hash 与 manifest 一致；复现像素比较记录 exact/差异；能力声明与默认开关一致。
