# 前端工作日志

本目录仅保存 CodePoet 前端工作日志。进行前端开发及前端相关任务的 agent，先遵守仓库根 AGENTS.md 和 frontend/AGENTS.md，在修改前端业务代码前建立开始记录，结束或中断前补充结果。纯后端开发不适用此前端日志要求；后端日志不得放入本目录。跨前后端任务在此仅记录前端部分。

## 文件命名与维护

- 使用 Asia/Shanghai 日期：YYYY-MM-DD-简短主题.md。
- 一个任务一份日志，继续同一任务时更新原文件；同日不同任务使用不同主题。
- 保留历史结论的时间背景，后续进展以追加说明记录，不将过去的阻塞误写成已解决。
- 记录实际命令与结果；未执行检查明确标注；不写入认证信息或密钥。

```markdown
日期：YYYY-MM-DD（GMT+8）
任务 ID：如 P0-03，无则写任务名称
状态：进行中

## 开始记录

- 目标：
- 允许修改范围：
- 初始 Git 状态：
- 执行计划：
- 已知阻塞：

## 实际改动与决定

工作推进时追加。

## 验证结果

- 命令/操作：
- 实际结果：
- 未执行/未验证：

## 结束记录

- 状态：已完成 / 部分完成 / 阻塞 / 中断
- 未完成事项与下一步：
- Git 提交/推送情况：仅记录实际观察
```
