## 结论

在独立 SQLite、真实 FastAPI、Next 生产构建和 Chrome headless 下，通过生产 UI 的“语义生成 → 外部知识图谱”表单验证：

- 3 个真实 Wikidata 实体均 HTTP 201 生成成功，来源快照进入 `generation.provenance.externalGraph`：
  - 莲 Q16528 → 站内 `knowledge-lotus`，10 条一跳关系，15 条 mappingDecisions；
  - 竹 Q670887 → 站内 `knowledge-bamboo`；Wikidata 中文标签为“竹亚科”，17 条关系，14 条 mappingDecisions；
  - 梅 Q157763 → 站内 `knowledge-plum`，9 条关系，14 条 mappingDecisions。
- 每个实体都验证了 `sourceId/externalEntityId/contentHash`、实体标签、`relations.length >= 2`、`mappingDecisions` 覆盖 `rule-selection` 与 `caption`；`GET /generations/{id}` 复核一致；页面来源快照可见。
- 莲保存为私有作品版本 `wv-bd3a9147c01742528382fa85ebea264e`；刷新重开后 `externalGraph` 仍存在；服务端像素比较 `exactMatch=true`、`mae=0`、`differentPixelRatio=0`。
- 错误路径与离线复现真实验证（11/18 补齐全部剩余项）：
  - UI 非法实体 ID（`Q 16528`）前端预校验拦截，未发请求；
  - UI/API 未知来源 → 503 `KNOWLEDGE_GRAPH_UNAVAILABLE`，`details.available=["wikidata"]`；
  - **UI/API 未配置任何来源（`CODEPOET_KNOWLEDGE_GRAPH_SOURCES=""`）** → `GET /engine/capabilities` 返回 `features.knowledgeGraph=false`，UI 禁用表单并提示“当前部署未启用知识图谱来源；配置后才会显示入口。”，直调 API 返回 503 `KNOWLEDGE_GRAPH_UNAVAILABLE`（`details.available=[]`）；
  - **UI/API 来源超时（`CODEPOET_KNOWLEDGE_GRAPH_TIMEOUT_SECONDS=0.0001`）** → 504 `KNOWLEDGE_GRAPH_TIMEOUT`（`来源在 0.0001s 内没有响应`），UI 明确显示 `HTTP 504 · KNOWLEDGE_GRAPH_TIMEOUT` 且不伪造生成结果；
  - **关闭来源/离线状态下重开并复现已保存的 K1 作品** → 在 `CODEPOET_KNOWLEDGE_GRAPH_SOURCES=""` 下重开 `wv-bd3a9147c01742528382fa85ebea264e`，`externalGraph` 来源快照完整显示，点击“复现此版本”零外部图谱请求完成服务端像素比对（`exactMatch=true`、`mae=0`、`differentPixelRatio=0`）；
  - API 非法实体 ID → 422 `VALIDATION_ERROR`；
  - API 未映射实体 Q42 → 422 `NO_SEMANTIC_MATCH`。
- `pageErrors=[]`，`failures=[]`，`unverified=[]`。

## 关键环境要求（复跑必看）

首次运行主路径失败在 422 `NO_SEMANTIC_MATCH`，原因不是 K1 代码，而是隔离库只跑了 `scripts/seed.py`，没有跑 `scripts/seed_demo.py`：`knowledge_entities=0`、`mapping_rules=0`，外部实体无法映射到站内知识。

补跑一次幂等的 `scripts/seed_demo.py` 后，同一脚本 3 实体 + 保存/重开/复现全部通过。复跑 K1 UI 验收前必须确认：

```text
CODEPOET_DATA_DIR=<isolated-data-dir>
uv run --project backend python scripts/migrate.py
uv run --project backend python scripts/seed.py --reset-passwords
uv run --project backend python scripts/seed_demo.py   # 12 知识实体 + 8 映射规则
```

后端启动：

```text

CODEPOET_KNOWLEDGE_GRAPH_MAPPING_FILE=shared/demo/knowledge-graph-mappings.json
```
