# 代码诗接口文档：现行基线与提分阶段增量

> 修订：2026-11-12。本文主体保留v1.1基础演示协议，结合当前代码修正已确认状态；不再以「尚未实现应用」描述现状。提分阶段的新接口/字段单列于[接口增量约定](提分阶段接口增量约定.md)，全部标为待实施设计。
>
> 实施顺序：[新任务看板](交付计划与任务看板.md)。[openapi-core.json](openapi-core.json)与[openapi.json](openapi.json)为既有设计快照，不能代替运行时API。A按S0逐切片同步模型/契约；本次文档规划没有修改JSON或实现后端。原P0/P1-A/P1-B标识保留用于追踪，新增任务用S0/Q1/R1/R2/R3/S1/K1/X1/X2/F1。
>
> 本版改变保存协议：浏览器Canvas真实出图后上传，不再把服务端无头浏览器作为基础依赖。此前v1.0的renderJob/reproduce调用示例由本文替代。

## 1. 现行协议与新范围的关系

| 级别 | 含义 |
| --- | --- |
| P0 | 登录→模板参数→Canvas→PNG上传→私有作品保存/重开 |
| P1-A | 角色、知识/概念/标签、模板版本审核、历史/收藏/会话、筛选、导入导出/审计 |
| P1-B | 语义规则、JSON IR子树/裁剪、时间轴、来源与像素复现 |
| 原P1-C | 旧阶段名；新计划中的R1/R2/R3/S1提分目标，当前尚未启用的能力仍按capabilities关闭 |
| 原P2 | Q1质量为新主线、K1图谱有条件启动，X1 LLM/X2 GPU二选一；新协议见增量约定 |

当前核心契约有67个操作，完整契约保留79个操作。**操作数不是独立功能数或工日数**：多数是普通CRUD，同一POST /generations包含P0和P1-B不同分支。这是旧版端点目录数量，不代表运行时端点数。新计划恢复多后端和受限沙盒目标，但不要求服务端Chromium调度；实施由新任务ID与预算控制。

完整契约中的旧选做接口按实际实现逐个确认，不注册假成功路由；其中PATCH作品元数据和管理员下线已随main实现，其他不能由此推定可用。Core-demo只启用Canvas/browser_upload，选做后端不能因为Backend枚举里有名字就算已完成。

## 2. 全局约定

- 路径前缀 /api/v1，camelCase，字符串ID，响应时间UTC ISO 8601。
- 成功直接返回业务对象；201创建完成，202任务已受理，204无响应体。
- 列表 {items,total,page,pageSize}，默认1/20，最大100；createdAt降序、id降序。
- 数组query用重复参数，如tagIds=a&tagIds=b；跨维度AND、同维度OR；q为普通子串匹配。
- 可编辑对象revision从1起，写入expectedRevision；冲突409。DELETE的expectedRevision放query。PATCH省略字段不变，数组整体替换；null仅能清空可空字段。
- 对象ID/ownerId/revision/状态由服务端产生，不能允许客户端直接写role=admin或status=published。
- JSON普通请求≤256KiB；导入JSON≤5MiB；上传PNG≤5MiB、multipart≤6MiB；后端仍校验解码尺寸。
- JSON/产物返回Cache-Control:no-store；错误/响应带X-Request-Id，可用X-Parent-Request-Id关联调用。
- 字段、必填、长度和枚举的完整定义在核心OpenAPI components.schemas；本文说明业务条件，不另造第二套字段名。

### 2.1 登录与权限

1. GET /auth/csrf 建匿名认证上下文，返回csrfToken/expiresAt。
2. 全部POST/PATCH/PUT/DELETE带X-CSRF-Token，包括注册/登录；Cookie自动附带，前端credentials:include。
3. POST /auth/login 成功轮换codepoet_session和CSRF，返回AuthSession={user,csrfToken,expiresAt}。
4. Cookie HttpOnly、SameSite=Lax、Path=/，生产Secure；匿名30分钟、登录8小时。刷新用GET /me恢复，不在localStorage存密码/会话。
5. 公共查询可匿名；mine/favorites/manage等私有scope必须登录。失效Cookie访问公共内容按匿名处理，不因此放行私有数据。

权限：G=公共读；L=登录；O=本人资源（管理员只读管理）；V=本人/管理员/公开作品具体版本/待审版本授权关联快照；V写操作仍须登录；D-own/A=developer本人模板或admin；E/A=expert/admin；A=admin；AnonWrite=匿名CSRF写入。

模板/作品审核禁止自审。私有generation/job/session/产物不可通过ID猜测访问。审核人只能看待审目标引用的数据，不能遍历作者其他历史。

### 2.2 统一错误

```json
{"error":{"code":"PARAMETER_OUT_OF_RANGE","message":"中心半径必须在8到80之间","fieldErrors":[{"path":"params.centerSize","message":"最大80"}],"requestId":"req-42","details":null}}
```

| HTTP | 典型code | 处理 |
| --- | --- | --- |
| 400 | INVALID_JSON/INVALID_QUERY | 修请求格式 |
| 401 | AUTH_REQUIRED/SESSION_EXPIRED/INVALID_CREDENTIALS | 登录；不区分账号是否存在 |
| 403 | FORBIDDEN/CSRF_INVALID/SELF_REVIEW_FORBIDDEN | 提示权限/获取新token |
| 404 | RESOURCE_NOT_FOUND | 不存在或无权读私有资源，统一返回 |
| 409 | REVISION_CONFLICT/INVALID_STATE/GENERATION_JOB_MISMATCH/FRAME_ALREADY_EXISTS/UNPUBLISHED_SOURCE | 显示原因并刷新/重试 |
| 413 | REQUEST_TOO_LARGE | 缩小JSON/PNG |
| 422 | VALIDATION_ERROR/IR_INVALID/TAG_CONFLICT/ONTOLOGY_CYCLE/NO_SEMANTIC_MATCH/UNSUPPORTED_CAPABILITY | 定位字段/节点 |
| 429 | EXECUTION_BUSY | 当前用户未完成上传任务过多，恢复/取消旧任务或等待过期 |
| 503 | BACKEND_UNAVAILABLE | 已实现能力的运行环境暂不可用 |
| 500 | INTERNAL_ERROR | 显示requestId，不返回堆栈/磁盘路径/密码 |

基础版未启用CSS/Turtle/WebGL时，选它们返回422 UNSUPPORTED_CAPABILITY；不把“未实现”说成“暂时渲染成功”。任务自身失败在GET任务的200响应里用status/error表示。

## 3. 当前IR与能力

GET /engine/capabilities 返回profile=core-demo、四项backends、features和当前限制。当前基线Canvas available=true，executionModes=[browser_upload]；其他三个available=false、executionModes=[]，给unavailableReason。

features：当前semanticGeneration/subgraphEditing已启用；dslSandbox/advancedPolicies/headlessRendering/selectiveExport/workSnapshotImport=false。

| 项目 | Core-demo约束 |
| --- | --- |
| 画布 | 800×600；viewport为内部整数裁剪矩形 |
| 节点 | group/circle/polygon/polyline；≤200节点、2000顶点、4层 |
| 坐标 | 左上原点，x右/y下；T×R×S，顺时针正角度；坐标绝对值≤8192 |
| 样式 | #RRGGBB/null，opacity逐叶乘祖先，strokeWidth最终逻辑像素不随缩放变化 |
| 图形 | circle半径0.1～2048、64段；polygon非自交非零面积 |
| 动画 | 静态durationMs=0，否则1000～5000ms；x/y/rotation/opacity线性，每属性一轨 |
| 采样 | 时间前from、时间后to、中间线性，覆盖基础值；同一clock，不重新随机 |
| 模板 | generatorRef=ir、fragmentSource=null；参数≤16，声明式bindings |
| 材质 | flat；禁止任意JS/Python/GLSL/HTML/外链图片 |

DrawingIR完整字段：schemaVersion、seed、canvas、viewport、durationMs、nodes、animations、narrative。节点id唯一，parentId只指group，无循环；transform可省略补默认，返回展开默认。静态变换仍有scaleX/scaleY，当前不接缩放动画。

narrative={timeMs,entityIds,caption}，timeMs在作品范围；来源快照包含关联实体当时内容。新模板supportedBackends当前只能[canvas2d]。

## 4. 账号、知识与普通管理CRUD

### 4.1 账号

POST /auth/register：username、password必填，nickname/requestedRole可选。username3～32英数下划线，password10～128；始终返回role=creator，其他角色产生pending申请，不自动登录。

User含id/revision/username/nickname/bio/role/status/roleApplication/permissions和时间，不返回密码哈希。PATCH /me只改nickname/bio。

admin role-decision：expectedRevision、approved、role、reason；必须对应当前待申请角色，禁止自己审批。管理员种子创建，四角色都有普通创作能力。

### 4.2 知识/概念/标签

| 请求模型 | 创建必填 | 可选/默认 | 附加规则 |
| --- | --- | --- | --- |
| KnowledgeCreate | type/name/summary/content | aliases/sourceReferences/conceptIds/tagIds/relations=[]，timeTheme=null，status=active | type=person/story/concept/symbol；引用active；来源URL仅http/https |
| ConceptCreate | name | description空串、parentId=null、status=active | 单父树防环；active子节点存在时不能停用父节点 |
| TagCreate | name | 同Concept，conflictsWith=[] | 互斥对对称维护，继承后检测冲突 |

知识name≤80、summary≤500、content≤20000；别名≤20条；sourceReferences是title/url/note，relations是predicate/targetEntityId。返回inheritedTagIds/effectiveTagIds。

更新模型=expectedRevision+至少一项待改字段；DELETE软停用，保留历史。概念/标签详情直接从完整分页列表取，不必实现选做GET单项接口。manage scope仅E/A。

### 4.3 模板与参数

TemplateCreate={metadata}，metadata显式包含name/description/entityIds/tagIds/symbols/timeTheme。容器工作元数据仅作者/管理员可见；公共metadata来自发布版。

VersionCreate两种：新建至少irTemplate/parameterSchema/supportedBackends；克隆至少fromVersionId。新建metadata默认工作元数据、generatorRef=ir、bindings/constraints=[]、fragmentSource=null、ontologyVersion=当前、changeNote空串。响应TemplateVersion。

参数definition：name/label/description/type/default；number/integer还有min/max/step；enum有options；boolean/color对应类型。number步进用于UI，整数必须整数；default也必须合法。

绑定示例：{parameter:centerSize,nodeId:heart,property:geometry.r}；路径必须白名单且类型匹配。约束仅参数范围/枚举、lessThan、布尔互斥。不要运行数据库里的表达式代码。

PATCH /templates只改工作元数据；不改已发布快照。PATCH版本只允许draft/rejected。比对先GET两份只读版本JSON由B计算字段差异，选做compare接口当前不必实现。

## 5. 审核、版本与私有空间

### 5.1 审核状态

```text
模板：draft -> submitted -> published / rejected；published -> archived
作品：private -> pending_review -> published / rejected
```

submit带目标版本expectedRevision。ReviewCreate={targetType,targetId,expectedRevision,decision,reason}，decision=approve/reject，拒绝理由非空，禁止自审。

送审重验IR/参数/引用；事务内写审核记录和状态/公开指针。已发布内容不可修改，只能新版本。待审新作品不替换旧公开版；归档当前模板清除它的公开指针，历史作品仍可复现。

draft/rejected可由作者私有预览，generation.unpublishedSource=true；派生一直保留，作品不得公开送审。模板后来通过不会改旧generation，需重新生成。

### 5.2 会话与快照（少一个接口）

CreationSession={id,revision,ownerId,name,state,latestSnapshotId,...}。state含mode/templateVersionId/params/semanticInput/draftIR/fragmentSource/backend/seed/timelineTimeMs/selectedNodeId/generationId，当前mode仅template/semantic/ir，fragmentSource=""。

- POST /sessions 创建现场并追加首个snapshot，返回CreationSession。
- PATCH /sessions/{id}接expectedRevision和name/state；**每次用户显式保存时，同事务追加snapshot**，session revision只加1。
- GET /sessions/{id}/snapshots查看历史。
- POST /sessions/{id}/restore接snapshotId/expectedRevision，保存恢复前与恢复后快照，更新现场，不自动执行代码，返回{session,snapshot}。
- 不要求单独POST /sessions/{id}/snapshots；它作为P1-C辅助接口保留。

WorkVersion是绑定generation+成功renderJob的成品版本，与编辑现场不同。个人空间用作品/收藏/会话列表，不再开发通用撤销系统。

## 6. 生成、规则语义与JSON片段

### 6.1 三个模式

```json
{"mode":"template","templateVersionId":"tv-1","params":{"centerSize":24},"seed":42,"backend":"canvas2d"}
```

```json
{"mode":"semantic","input":{"text":"以竹节表达守正","entityIds":[]},"params":{},"seed":42,"backend":"canvas2d"}
```

手改模式：mode=ir、baseGenerationId、完整ir、backend，不另外传params/seed。base必须本人或当前公开版本可见，新generation归操作者，标manual_edit。

template/semantic params默认{}、seed默认42；不认识/越界参数返回422。semantic至少text/entityIds一项非空；无匹配返回NO_SEMANTIC_MATCH。

Generation返回id/ownerId/mode/backend/ir/params/seed/templateVersionId/unpublishedSource/irHash/provenance/validationReport/warnings/requestId。是不可变快照，不是图片成功证明。

provenance由A生成，包括知识内容/规则内容和版本、符号/色板/构图/叙事依据、冲突、engineVersion/ontologyVersion/policyRevision；不接受客户端伪造推理。基础版fragmentSource/hash为null，常量配置版本可记1。

### 6.2 映射规则

MappingRule包含name/enabled/priority/match/effects/explanation、version/revision。match=keywords/entityIds/conceptIds/tagIds/operator，至少一个非空；any命中任一条件组，all命中每个非空组。按priority降序、ruleId升序决策。

effects的symbolIds=lotus/bamboo/water/narrative；当前种子模板只准备莲/竹/叙事；palette是1～8色，composition=centered/vertical/horizontal/radial，motion=none/sway/reveal。规则决定模板/参数/有限动画，再生成合法IR。

规则列表返回完整内容，编辑不必调用选做GET /rules/{id}；PATCH增加version/revision，旧generation保留旧规则。

### 6.3 子树/裁剪

B从完整IR按parentId提取编辑子树，祖先只读，无需先GET子图。POST /generations/{id}/subgraph传rootNodeId/replacementNodes和可选viewport。

替换根保留旧id/parent；新节点不能撞外部ID或引用外部新父节点。动画悬空返回IR_DANGLING_REFERENCE；只裁剪时提交原子树+viewport。返回{generation,changedNodeIds,removedNodeIds}，新generation保留来源限制。

JSON IR不执行脚本，不能宣称AST沙盒已经完成。DSL编辑器和/sandbox-runs为选做。

## 7. 保存协议：浏览器真实绘制→上传帧

### 7.1 创建上传任务

```json
{
  "generationId":"g-1",
  "backend":"canvas2d",
  "executionMode":"browser_upload",
  "timesMs":[0],
  "rendererVersion":"canvas-1.0.0",
  "clientEnvironment":{"userAgent":"使用navigator.userAgent实际值","deviceScaleFactor":1}
}
```

POST /render-jobs返回202的RenderJob。普通任务generation必须本人。设计要求rendererVersion与capabilities一致，但代码复核发现当前能力声明p0-03.1、浏览器实际codepoet-canvas-1.0.0，建任务服务仅记录客户端值；S0应先统一声明再加严格校验，不能把此要求当作已经实现。

- 状态running、phase=awaiting_frames，expiresAt为5分钟后，manifest/qualityReport/error=null。
- 每用户最多两个未完成上传任务；过期时检查并标timed_out，error.code=UPLOAD_EXPIRED，不需常驻worker。
- 静态[0]；动画保存必须[0,floor(duration/2),duration]，最多3帧。普通预览可只取某个合法时刻，但不能当完整动画保存。
- IR/输入校验继续执行；新任务rendererVersion严格兼容校验属于S0待补项。创建任务本身不证明图片已出。

### 7.2 上传帧

POST /render-jobs/{id}/frames，multipart/form-data：

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| file | 是 | PNG Blob，≤5MiB，真实解码后尺寸=viewport，忽略文件名 |
| timeMs | 是 | 整数，属于任务timesMs |
| irHash | 是 | 64位小写十六进制，等于数据库generation.irHash |

带Cookie/CSRF；浏览器自动设置boundary，不能手写Content-Type。A检查归属/任务时效/模式/尺寸和大小，自行计算SHA-256。相同时刻相同内容重传返回200当前任务，不同内容409 FRAME_ALREADY_EXISTS。

返回200完整RenderJob：未收齐仍running/awaiting_frames；齐全后succeeded/completed、manifest/qualityReport非空。失败/timed_out/cancelled为phase=finished，error非空，不能保存作品。

### 7.3 清单、质量与信任边界

manifest含generationId/backend/outputSource/rendererVersion/environmentHash/irHash/dependencySnapshotHash/viewport/timesMs/frames/archiveArtifactId。frame={artifactId,sha256,width,height,timeMs}；多帧ZIP带manifest，静态archiveArtifactId=null。

outputSource=browser_upload表示客户端真实Canvas导出后上传；服务端只验证文件、身份和一致性，**不能证明像素一定忠实于IR**。该边界已接受，不额外开发服务端可信执行证明。

qualityReport记录每帧非背景RGB比例（当前实现差阈值8，以返回pixelDifferenceThreshold为准）、顶层平均和emptyOutput；完全空白给警告。validationReport记参数/节点/完全出界数。不要把它称作高级艺术质量评分。

GET /artifacts/{id}鉴权返回PNG/ZIP，不返回磁盘路径。非本人只能读当前公开作品授权产物。

## 8. 作品、历史、收藏与真实复现

### 8.1 保存作品

```json
{"title":"清正莲心","description":"演示作品","generationId":"g-1","renderJobId":"rj-1"}
```

POST /works返回201 {work,version}，versionNumber=1/status=private。A验证本人generation/普通job匹配、任务成功、所有帧真实存在和时刻完整；不接受上传一张任意截图直接跳过任务绑定。

GET /work-versions/{id}返回{workVersion,generation,renderJob}。创建新版本POST /works/{id}/versions接Work.expectedRevision、generationId/renderJobId/changeNote；旧内容不覆盖。当前已实现PATCH /works/{id}修改工作元数据（带expectedRevision），不原地更改已发布快照；新版本消费工作元数据。管理员POST /works/{id}/unpublish已实现，公共可见性仍按发布版本/撤回状态校验。

作者displayVersionId=latestVersionId，公共displayVersionId=publishedVersionId。收藏PUT幂等，DELETE没有收藏也204；收藏列表只返回当前仍可见项目。

### 8.2 复现（不重新推理）

POST /work-versions/{id}/reproduce必须登录，JSON：

```json
{"rendererVersion":"canvas-1.0.0","clientEnvironment":{"userAgent":"使用navigator.userAgent实际值","deviceScaleFactor":1}}
```

返回202的新RenderJob，属于当前用户，generationId/原backend/timesMs来自旧版本，originalJobId固定。B从旧详情读IR，按时刻Canvas重绘，走同一frames上传；A不启动无头浏览器、不查询当前规则重新推理。

齐帧后GET /render-jobs/{新ID}/comparison?originalJobId={原ID}。必须两任务成功且绑定原任务一致。A解码RGBA，返回compatible/reason/exactMatch/mae/differentPixelRatio/逐帧结果。

环境提示使用浏览器自报UA、DPR=1、rendererVersion和尺寸；不是完整硬件认证。不同声明/版本/尺寸时compatible=false、指标null；相同也要实际逐像素比较：MAE为RGBA绝对差均值/255，不同像素比为任一通道不同的像素比例。

他人的公开作品可复现，但要存为自己的普通作品应先mode=ir派生本人generation，再新建普通任务。不能把别人的generation/job直接绑定自己作品。

## 9. 基础导入导出与日志

- GET /audit-logs仅admin，按actor/action/targetType/time/requestId分页；只读，避免密码/Cookie/完整凭证。
- POST /admin/exports接types，ids省略或{}；当前不提供按ID选择。按类型导出小包并补本库引用，≤5MiB。
- BackupPackage={schemaVersion,exportedAt,manifest,data}；data六数组concepts/tags/entities/rules/templates/workSnapshots，manifest.counts记实际数量，includesArtifacts=false。
- POST /admin/imports/validate：当前CoreImportPackage每类≤100，workSnapshots必须[]；结构错误422，引用/冲突错误200 valid=false，返回validationId/contentHash/expectedDataRevision/expiresAt/counts/errors。
- POST /admin/imports/apply：validationId+expectedDataRevision，同管理员10分钟有效、单次消费，事务重验，重复ID整批拒绝，不能部分成功。
- 导入模板一律draft/归当前管理员，不创建原用户；作品IR只导出备份，不声称能恢复图片/已发布作品。
- 演示恢复用只初始化管理员的干净测试库，不能覆盖当前开发数据；完整数据库+图片备份另按启动交付文档处理。

安全策略管理与DSL接口为P1-C；当前本体/规则/模板参数约束可管理，沙盒开关在capabilities显示false，不做假配置/假运行统计。

## 12. 提分阶段变更结论

接口需要增量修改，原因是当前请求模型/模板写入锁定Canvas、RenderCreate锁定browser_upload，响应里保留其他枚举仍不能支撑真适配器。先处理后端选择、版本、server任务与复现，再处理质量/受限执行/条件项。

完整拟议字段、权限、失败行为与兼容要求见[提分阶段接口增量约定](提分阶段接口增量约定.md)。该文件优先描述未来目标；本文第2～11节继续说明现行基线，不能直接把未来请求发给当前服务。A实施后逐段修正文档并导出实际OpenAPI，B以真实接口样例接入。

代码衔接复核与LLM执行卡见[提分阶段执行细则](提分阶段执行细则.md)，包含现状与设计不一致之处；实施前应一起阅读。
