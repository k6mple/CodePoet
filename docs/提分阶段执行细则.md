## 2. 执行与交接规则

任务依赖：S0-A1与S0-B1可同时做 → R1-B1离线渲染 → S0-A2/R1-B2真实联调 → R2；Q1-A1与S0独立，Q1-B在报告协议固定后接入；S1环境探针通过后做S1-A/B；R3依赖Q1-A1几何与server契约；K1仅在真实来源门槛通过后执行；X1依赖S1，X2依赖R2及版本化渲染选项。每人一次只执行一个有验收输出的切片。

A交接包必须包含：任务ID/提交基线、API路径、真实请求与成功/失败响应、能力开关/支持范围、迁移与依赖、未完成事项。B交接包必须包含：rendererVersion、支持IR范围、fixture与PNG、保存/复现实际请求、页面错误和requestId。JSON字段名称按接口增量文档；如发现冲突，先修契约再改调用端。

每张卡的完成是「本卡结果已验证」，不代表整个父任务完成。共享接口A主写、B核对；现有Canvas缺陷先稳定再开放新后端。候选部署采用独立数据库/产物目录和显式配置，不能让公共部署声称未验证能力可用。

## 6. Q1-A/B：补齐算法输入与明确报告行为

### Q1-A1：先实现服务器采样（计入Q1预算）

### Q1-A2：质量报告与标注集

入口`services/quality.py::build_quality_report`、`schemas/works.py::QualityReport`；调用发生在`services/works.py::upload_frame`，新server最终化也必须调用。复用quality_report_json，无需仅为报告新增SQL列。

最小算法确定为：固定200×150逻辑mask（按viewport比例映射），背景/细线不足一个像素时做至少一像素覆盖；AABB筛候选，mask算独立主体交叠。候选主体以顶层子树归组，同组设计重叠不计主体冲突；这会漏报组内冲突，报告method明确限制，不能随意给IR添加allowOverlap字段。

色彩依据来自generation当时paletteDecision/matchedRules；无依据not_applicable。取归一化RGB到允许色板的最小欧氏距离作可解释初版指标，按可见像素面积加权；显式把描边色排除或列独立规则，不能把现有深色轮廓全判违规。

信号mask来自采样几何，实测前景继续用当前背景差阈值8。输出mask内前景数S、mask外前景数N，代理SNR=10log10((S+1)/(N+1))；空白单独fail，避免空图因N小得到高分。抗锯齿容差、mask膨胀半径固定在算法版本内。对新增杂点PNG和真实正常PNG对照，不对正常复杂纹样做无根据的审美判断。

先给value/method/status；score可以null，未校准前不编综合评分。报告证据最多100条、建议最多20条，节点ID与时刻必须能对应原IR。12标注样本至少6坏例，记录误报/漏报；阈值经这组样本确定后写入version化报告，不能靠调到测试全过宣称泛化。
