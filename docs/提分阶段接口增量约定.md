## 2. 后端选择和能力

GenerationCreate的template/semantic/ir三分支统一接受backend∈canvas2d/css/webgl/turtle；不增必填字段。模板分支必须在supportedBackends中，语义分支沿当前规则synthesize/build_ir直接生成IR（templateVersionId/templateSelection可为null），再校验目标后端能力；IR分支验证目标能力并继承baseGeneration的来源限制。subgraph派生保留原backend。不支持返回422 UNSUPPORTED_CAPABILITY与details（backend、unsupportedProperties），无静默fallback。

同一IR允许多个backend；换后端创建新generation/job，不修改原generation.backend或irHash。Canvas既有请求完全兼容。

GET /engine/capabilities保留profile=core-demo和现有字段；每个backend的rendererVersion独立版本化，不再绑定统一ENGINE_VERSION。S0先将Canvas能力声明对齐实际codepoet-canvas-1.0.0，再加入新任务版本校验；本轮已统一Canvas声明与新任务版本校验；CSS候选为codepoet-css-1.0.0，默认仍Canvas，候选配置显式包含css。旧job/manifest不回写版本，无法执行的旧版本明确不兼容。浏览器三后端executionModes=[browser_upload]；Turtle=[server]，supportsContinuousPlayback=false，animationProperties表示可确定时刻采样的属性。后端不支持的节点/透明度/动画需显式拒绝，不能仅靠列表空项猜测。

新增可选features：qualityAssessment、knowledgeGraph、llmAssistant；缺失按false。dslSandbox/advancedPolicies只有S1通过真实防护/策略验证后true。headlessRendering仍false，因为Turtle server不等于Chromium无头服务。selectiveExport/workSnapshotImport保持当前false。

运行环境不可用时对应available=false并提供unavailableReason；浏览器局部WebGL可用性还要本地context探针，不把服务端声明当GPU保证。全局200节点等上限保持原值。

## 3. RenderCreate：判别上传与server

| 字段 | browser_upload | server |
| --- | --- | --- |
| generationId | 必填，本人generation | 必填，本人generation |
| backend | canvas2d/css/webgl，必须等于generation.backend | turtle，必须等于generation.backend |
| executionMode | browser_upload | server |
| timesMs | 静态[0]，动画完整保存三时刻 | 同左，由服务端同一校验函数校验 |
| rendererVersion | 必填，匹配目标后端capabilities | 可省略；若给出必须匹配，最终由服务端记录 |
| clientEnvironment | 必填，原结构UA/DPR=1 | 不允许携带，由服务端生成运行环境快照 |

POST /render-jobs → 202 RenderJob。浏览器保持running/awaiting_frames与5分钟上传TTL；Turtle为queued或running/rendering，经受控worker完成。禁止接受URL、命令、路径、用户Python作为server输入。server执行有独立墙钟限制/并发配额，不使用上传TTL代替。

沿用GET /render-jobs/{id}、POST /render-jobs/{id}/cancel查询/取消；取消后worker不能再改成succeeded。POST frames对server任务返回409 INVALID_STATE。所有帧存在、hash/尺寸/时刻匹配后才succeeded；失败无可保存manifest。POST /works仍只接受匹配本人generation与成功普通job，不区分输出模式绕过验证。

Manifest保留schemaVersion=1.0、backend/rendererVersion/outputSource/environmentHash/irHash/dependencySnapshotHash/viewport/timesMs/frames/archiveArtifactId；outputSource分别browser_upload/server。新增可选serverEnvironment到RenderJob，内容为rendererVersion、pythonVersion、turtleTkVersion、os、exporterVersion、deviceScaleFactor=1，全部由服务端产生且不含主机路径/密钥。客户端环境原字段不冒充server环境。

POST /work-versions/{id}/reproduce仍不接受指定backend；任务从原版本派生、模式从原后端确定。浏览器保留现有rendererVersion/clientEnvironment请求；Turtle允许空对象，服务端选择当前Turtle版本并比较历史环境。旧Turtle版本缺失或环境不兼容时返回真实不兼容/不可用原因，不换Canvas。comparison按原backend、版本、环境、尺寸、时刻检查后真算RGBA；跨后端比较是独立验收，不写入exactMatch承诺。

## 4. Q1：增量质量报告

RenderJob.qualityReport保留原字段（包括pixelDifferenceThreshold），新增可选assessment：

| 字段 | 类型/含义 |
| --- | --- |
| algorithmVersion | 字符串，固定算法版本 |
| evaluatedTimesMs | 整数数组，实际参与时刻 |
| thresholds | 对象，overlapRatio、paletteDistance、noiseRatio三个数值阈值 |
| metrics | 四项数组：parameterValidity/layoutConflict/colorSemantic/signalNoise |
| recommendations | 数组，code/message/nodeIds/timeMs；不含可执行脚本 |

每个metric={name,status,score,value,method,evidence}；status=pass/warn/fail/not_applicable/unavailable，score为0～100或null，value为数值或null，method为算法标识，evidence为有长度上限的结构摘要。score是项目内部量化指标，**不是赛题得分**；无依据时为null，不填100。layout evidence给节点对/交叠率，color给规则版本/违规颜色面积，signalNoise给mask版本/信号与杂散像素数量和proxy说明。

算法读服务端存储的IR/来源/真实PNG，收齐帧后评估并保存，不由前端上传自评分。历史任务无assessment继续可读且显示未评估。质量算法报错将status=unavailable并记录原因，不把原来成功作品变成无提示500；IR/参数非法仍按现行422拒绝。阈值随algorithmVersion固定，不新增大型质量配置后台。

代码核对发现旧正文写RGB阈值3，当前quality.py常量为8；本次正文修正为运行时报告字段为准，避免继续用旧值作为新契约。

## 5. S1：沿用预留DSL/策略接口

POST /sandbox-runs：SandboxCreate={baseGenerationId,source}；前者必须可读并可合法派生，源码≤16KiB。静态审计也产生可追溯run；请求格式错误仍400/422，成功受理202。GET /sandbox-runs/{id}归属校验，他人404。保留完整OpenAPI中的SandboxRun字段和JobStatus，成功generationId指向新不可变fragment generation，失败为null。

新增可选policySnapshot（本次有效限额/允许函数）、metrics.peakMemoryMiB、auditFindings；finding={ruleId,line,column,message}，仅记录有界脱敏错误，不回显内部路径。sourceHash、policyRevision和资源metrics必须来自实际执行。源码/策略快照由A在数据库审计关联存储，响应不暴露敏感信息。

GET/PATCH /admin/policies沿用Policies与PolicyUpdate={expectedRevision,values}。values/hardLimits字段保留原完整OpenAPI，但取值不得突破core-demo更小硬上限；新写入任务绑定当时快照，不被随后PATCH改变。增加只读auditRules=[{ruleId,description,enabled}]列出固定AST拒绝规则，禁止管理员上传可执行表达式/规则源码。本期仅允许调整enabledDslFunctions与DSL数值限额，其他预留策略值只读；必需AST安全规则不可关闭。

环境不可执行时POST返回503 SANDBOX_UNAVAILABLE；受理后的AST违规在run.error.code=DSL_AUDIT_REJECTED，资源熔断按failed/timed_out终态及DSL_CPU_LIMIT/DSL_MEMORY_LIMIT/DSL_CALL_LIMIT/DSL_STEP_LIMIT/DSL_TIMEOUT区分。HTTP错误和任务内部错误均保留requestId关联审计。

## 6. K1：最小图谱入口（满足来源门槛才实施）

POST /knowledge-graph/generations，登录/CSRF。请求={sourceId,externalEntityId,backend,seed}，backend按能力，seed缺省42；sourceId为部署配置白名单，不是用户URL。服务端固定超时/读取量，查询真实实体/属性/一跳关系，映射站内知识/规则后返回201 Generation，不把图谱调用混入每个普通generation。

Generation.provenance新增可选externalGraph={sourceId,externalEntityId,fetchedAt,dataVersion,contentHash,entities,relations,mappingDecisions}；数据版本无来源时dataVersion=null，contentHash必须有。entities含外部id/label/有界attributes，relations含id/type/fromId/toId/有界attributes，mappingDecisions说明哪些属性/关系影响哪个IR决策。最多50实体/100关系，快照仍受IR/请求与存储预算。来源凭据只在服务端配置。

503 KNOWLEDGE_GRAPH_UNAVAILABLE（缺配置/来源不可用）、504 KNOWLEDGE_GRAPH_TIMEOUT、422 KNOWLEDGE_GRAPH_ENTITY_NOT_FOUND、422 NO_SEMANTIC_MATCH；遵守统一envelope，不返回伪本地生成成功。来源授权与接口细节需A在K1探针中按真实服务补齐，不能推测外部字段。旧作品复现只读快照，不重新联网。

## 7. X1：LLM提案（条件冲刺，非当前必做API）

POST /assistant/proposals，登录/CSRF：{baseGenerationId,prompt,target,rootNodeId}，target=ir_fragment/parameter_schema；ir_fragment必填rootNodeId，parameter_schema不传rootNodeId，prompt≤2000字符；base必须可读且允许派生。202返回Proposal；GET /assistant/proposals/{id}仅归属可读。不得由客户端传任意模型URL/密钥。

Proposal={id,status,baseGenerationId,target,model,attempts,proposal,validation,error,createdAt,finishedAt}；status=queued/running/ready/failed，attempts≤2，proposal在ready前为null，validation={policyRevision,issues,isolatedValidationPassed}或null。A后台有限并发worker实际调用模型，超时30秒，最多一次修复；结果经过IR/参数校验和S1隔离校验，全部通过才ready。

POST /assistant/proposals/{id}/apply，无业务body，显式应用；返回201 Generation，重复apply返回原派生generation（不重复造版本）。ir_fragment限定为对base的合法子树替换；parameter_schema提案不得直接改模板版本/发布，先校验与base模板绑定兼容，应用默认值生成IR，模板schema采纳仍走新版本+审核。派生继承unpublishedSource限制。

需在实施时将只读provenance.assistant={proposalId,model,attempts,proposalHash,policyRevision}加入schema。缺服务503 ASSISTANT_UNAVAILABLE；非法提案/修复失败用任务error.code=ASSISTANT_VALIDATION_FAILED；无就绪提案apply返回409 INVALID_STATE。失败不覆盖当前generation。

## 8. 契约交付与兼容验收

A每切片同步运行时导出的OpenAPI、选定core/full设计文件、shared schema与示例；明确哪些optional字段只属未来。B检查类型/错误/模式分支，不能先把planned字段当必填。当前未实现的路由不注册假200。

最小兼容矩阵：旧Canvas生成/上传/会话/重开/复现；三浏览器backend真实上传；Turtle server查询/取消/保存/复现、拒绝frames；未开放backend拒绝；模板新版本支持集合；质量旧数据；DSL策略与跨用户；若K1/X1启用，真实来源/模型成功及失败、不可见资源404。接口字段存在、单元测试通过、真实联调通过分别记录。

## 9. 代码复核后的必要补充

实施细节与当前文件/函数映射见[执行细则](提分阶段执行细则.md)。以下修正属于拟议设计，尚未实现：

- shared/schemas当前只有README，没有可直接同步的独立schema实现。Pydantic为运行时依据，保留现有OpenAPI业务注解并逐项比对；不要自动复制第三套完整模型。
- 候选能力在隔离联调环境显式配置启用；S0基础卡只保证旧Canvas与未启用后端拒绝，CSS/WebGL端到端完成归R1/R2。验收后才默认开放，解除循环依赖。
- serverEnvironment必须持久化至新增可空server_environment_json列；旧任务null。queued/running任务在服务重启后明确failed/WORKER_RESTARTED；取消和完成以条件更新争抢终态。仅browser_upload走上传TTL。
- comparison明确比较backend、executionMode、rendererVersion及对应环境。现有实现主要比较浏览器UA/DPR/版本/时刻；新增server任务不能把空UA相等当环境一致。
- S1的EditorState新增mode=fragment、fragmentSource≤16KiB UTF-8、可空fragmentBaseGenerationId；旧记录字段缺失按null。恢复只恢复草稿，不能自动执行，执行后的generationId不能覆盖片段基础ID。
- DSL成功是在base上追加确定性图元；set_param仅允许未手改且有模板来源的base，并先参数实例化再追加；超IR限额整次拒绝。源语义见执行细则，不能由两个agent分别发明覆盖/追加行为。
- Policies里非DSL数值在v1保持只读，修改返回422 POLICY_FIELD_READ_ONLY；不能把新增通用策略管理藏在原11小时预算内。
- externalGraph/assistant随IR、子图、DSL派生保留历史来源并纳入依赖快照hash。外部实体ID不填入只接受站内ID的narrative.entityIds；没有内部映射时展示外部快照，不生成无效知识详情链接。
- LLM的ir_fragment提案固定{rootNodeId,replacementNodes}；parameter_schema固定{parameterSchema,bindings,defaults}且仅支持未手改模板base，其他返回422 ASSISTANT_UNSUPPORTED_BASE。apply在临时定义中实例化，保存提案及其hash，不原地改模板；重复apply同事务保护，返回同一generation。重新校验base当前可见性。
- X2渲染效果需要独立版本化renderOptions并纳入渲染输入hash/manifest；这部分需在X2准入时由A补正式字段契约。未补齐不实施可保存后处理，不能将页面临时状态当作历史作品输入。自动降采样仅限预览，保存固定DPR=1。
