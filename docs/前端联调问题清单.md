### BE-FAVORITES-READ-001：收藏写入后读取仍为 false，收藏列表为空

- 复现：creator 页面保存作品 → 点击“收藏作品”，PUT `/works/{id}/favorite` 返回 200 / `isFavorite=true` → GET `/works/{id}` 返回 200 / `isFavorite=false`，GET `/works?scope=favorites` 返回空页；刷新页面又显示“收藏作品”。
- 只读根因：`backend/app/services/works.py` 的 `build_work` 写死 `isFavorite=False`，`list_works` 的 favorites 分支仍返回占位空页；独立的收藏写服务已落库。
- 预期/回归：GET 根据当前账号的收藏关系返回标记，favorites 真实过滤可见作品并分页；刷新后仍显示取消收藏，取消后列表移除且第二账号收藏独立。
- 前端未缓存假状态或用本地存储替代服务端读取。

### BE-WORK-PUBLIC-POINTER-001：新增/待审版本使匿名作品详情指向私有新版本

- 复现：真实生成保存 v1，expert 通过发布 → 作者基于旧版修改 IR、上传并保存 v2，再送审 → 匿名 GET `/works/{id}` 中 `publishedVersionId` 仍为 v1，但 `displayVersionId` 为 v2；匿名 GET v2 为 404。
- 影响：公共列表按 displayVersionId 打开时进入不可访问版本；本轮未观察到匿名取得 v2 图片，不能将此问题描述为私有 PNG 已泄露。
- 只读根因：`create_work_version` 总是把容器 `display_version_id` 切到新私有版本，`build_work` 未按访问者选择 publishedVersionId。
- 预期/回归：作者/管理员可按约定查看最新版本，公共读保持 v1；v2 批准后切换，退回时不变；旧 IR/产物保持不可变。
