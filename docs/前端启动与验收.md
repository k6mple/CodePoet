## 启动

在仓库根目录执行。依赖已安装时可直接构建。

```powershell
uv sync --project backend --locked
.\scripts\setup-node.ps1
.\scripts\npm.ps1 ci
.\scripts\npm.ps1 run typecheck
.\scripts\npm.ps1 run build
```

分别启动 `./scripts/dev-backend.ps1` 和 `./scripts/npm.ps1 run start`，访问 [创作台](http://127.0.0.1:3000)。验证时使用干净的测试数据库和产物目录，按当前后端分支的迁移与种子说明准备四角色。若需要重新构建，先停止生产前端服务。

## 顺序验收

| 阶段 | 操作 | 验收信号 |
| --- | --- | --- |
| G0 | 创作者登录，选择已发布模板，修改参数后保存。新标签打开版本链接，再用第二个账号访问同一私有版本及产物 URL。 | 调参改变图形，超界保留旧图。保存返回版本，刷新后 PNG 和 IR 可读取，另一账号收到 404。 |
| P1A-01/02 | 注册并申请角色，管理员审批。按实际权限进入知识管理，维护知识、概念与标签，尝试创建父树环和互斥标签组合。 | 菜单与权限随审批更新。正常写入可重读，防环与冲突有明确反馈。 |
| P1A-03/04 | 新建并克隆模板草稿，在创作台私有预览，再送审。换审核账号退回或通过，确认公共模板库和作品列表。 | 草稿派生作品不可送审，退回理由可见，新版本待审期间公开页继续指向旧发布版。 |
| P1A-05/06 | 调参保存两次进度，恢复旧快照，再保存作品新版本。在公开作品页收藏后从个人空间打开。为模板或知识叠加两个检索维度。 | 快照和成品版本分别保留历史。新版本绑定成功上传任务。收藏状态刷新后持久，筛选条件保留在 URL。 |
| P1A-07 | 使用隔离库测试无效 JSON 包，再预校验并导入合法包，导出备份，查询审核与知识修改的审计记录。 | 无效包无部分写入，导出清单与实际数量相符，审计可通过 requestId 追溯。 |
| P1B-01/02 | 输入“莲花清正”和“竹节守正”，再从知识详情发起生成。编辑完整 IR，选择子树替换并输入四个裁剪值。 | 两种语义返回不同 IR 和来源依据。非法修改保留旧画面，合法提交返回新快照。 |
| P1B-03 | 在创作台播放和定位叙事节点，打开知识链接，保存动画并重开。 | 开头、中间和结束采样 PNG 均可读取，连续动画可由历史 IR 重绘，作品详情可查看创作时知识快照。 |
| P1B-04/05 | 变更规则后复现旧作品，对照同一时刻的原始与复现 PNG。查看参数、节点、出界和空白检查，按演示流程走完整场。 | 复现使用历史 IR 和原始采样，像素结论取自服务器响应。演示使用实际导入和审核的模板以及真实保存的作品。 |
