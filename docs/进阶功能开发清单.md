## 2. S0：先打通现有硬编码

A更新GenerationCreate三分支、TemplateVersion写入supportedBackends、RenderCreate、会话backend/mode、能力feature字面量和服务校验；不仅改响应enum。定义browser_upload/server判别，Turtle复现继承server模式，旧Canvas请求不增必填字段。

B定义最小Renderer协议load/seek/toPNG/dispose、共用clock与数值采样；BrowserRenderer有canvas2d/css/webgl三实现，Turtle走任务PNG展示而非伪造浏览器Renderer。保留原Canvas版本和旧快照行为，禁止大改所有页面。

验收：旧G0/复现通过；unsupported backend明确拒绝；一个新后端真实generation→job请求能走通，再扩第二个。契约细节见[增量约定](提分阶段接口增量约定.md)。

## 3. Q1：质量治理，先争取附加10分覆盖

| 指标 | 最小算法与解释 | 必须有的对照 |
| --- | --- | --- |
| 参数合法性 | 沿用服务器参数/IR校验，保留具体字段/节点错误 | 合法与越界参数，不给非法输入生成「优秀」报告 |
| 布局冲突 | 采样世界几何；AABB仅作候选，圆/多边形/线段实际相交或固定分辨率逐节点mask估计交叠；排除父子容器、设计允许重叠组 | 意图叠放莲瓣不误报、两独立主体遮挡报警；给nodeIds/timeMs/重叠率 |
| 色彩语义 | 基于命中规则色板/人工维护主题色约束，量化颜色到允许色板的距离/面积占比；报告依据规则版本、阈值 | 同IR合规与违规色；无语义约束时not_applicable，不武断宣称某色天然不廉洁 |
| 输出信号/噪声 | IR世界几何的前景mask（含stroke/抗锯齿容差）为期望信号区域，PNG非背景像素为观察；统计mask内有效前景、mask外杂散像素、碎片率，给代理SNR/置信说明 | 正常、空白、故意杂点、主体外涂抹、细线；不能把覆盖率直接改名SNR |

像素算法的阈值与version随报告保存；以至少12个标注样本（至少6坏例，覆盖三模板/三时刻）校准。质量不是艺术审美真值，SNR是明确的工程代理；正常样本误报须记录并限制评分适用范围。报告给「主体移开/降低密度/恢复主题色」等具体建议，不自动篡改保存作品。

用户可按建议创建新generation再评估，展示前后指标变化；低质量默认警告，非法参数仍阻断。历史作品未重评显示未评估，不回填假分。避免大规模CV/模型训练。

## 4. R1/R2/R3：一份IR，四种真实执行

共同基准：group/circle/polygon/polyline、flat、静态TRS、opacity父链逐叶相乘、viewport、绘制顺序、背景、统一64段圆和线宽语义；浏览器动画x/y/rotation/opacity线性，0/中间/结束，边界与父子组合fixture。

### R1 CSS

DOM/SVG图元 + CSS/WAAPI动画，统一clock显式seek。transform-origin与项目局部原点一致；不能用容器淡入或Canvas背景冒充。导出冻结目标时刻的属性/样式，SVG栅格化可用Canvas编码，但不重新用Canvas画几何替代CSS输出。禁止外部图片/字体/HTML，保证导出无跨域污染。

真实验证连续播放、随机seek、裁剪/透明、动画dispose；同IR三帧PNG→上传→作品→刷新→原后端复现。导出不了只算探针，不启用可保存能力。

### R2 WebGL

真实context/shader/buffer/draw；复用采样/矩阵，polygon三角剖分，polyline/描边三角化，不能靠跨设备不稳定宽gl.LINES。正确y轴、绘序、alpha混合/预乘规则、viewport；从真实帧缓冲导出并处理翻转。用户shader不开放。

验证凹多边形、透明交叠、父子变换、裁剪、三时刻、PNG保存/复现；context loss给错误/恢复或重试，dispose释放资源。环境不支持返回不可用，不换Canvas继续贴WebGL标签。

### R3 Turtle

目标环境先跑标准turtle.RawTurtle/TurtleScreen→Tk→固定尺寸PNG→释放进程；明确Tk/显示服务/PS转换等依赖是否可用。实际以目标部署机器为准，不以开发机截图代替。

Turtle真实执行几何，Pillow仅用于转换、透明分层/合成、裁剪/比较；逐层alpha需要原绘制顺序正确合成，不可静默忽略opacity。每个请求固定入口/受控目录/超时，不接收用户Python/命令/路径；关闭笔动画/箭头，统一坐标翻转和64段圆。

支持静态及动画IR的0/中间/结束离线采样，不要求实时连续播放。若只能做静态，capability必须拒绝动画，不宣称动画一致。server任务有终态/取消/超时/错误，无残留窗口/子进程；保存、重开、原后端复现与下载鉴权均贯通。

跨后端不强求PNG hash相同。用几何位置/颜色/时刻对齐和有阈值的区域差异报告验收；同一后端、同版本、兼容环境才追求旧作品像素复现。

## 5. S1：受限可编程 + 可验证防护

采用Python风格DSL，ast.parse后白名单解释为IR，不使用eval/exec/compile执行源码。允许circle/polygon/polyline/set_param、单层有界for range；保留当前JSON IR编辑作为稳定路径。

- 禁止import、属性访问、索引/反射、while、函数/类/lambda/推导式、I/O；静态规则有固定ruleId/行列定位，不开放管理员编写可执行规则。
- 源码≤16KiB，AST≤2000节点、循环≤200、深度≤1、步数/数值/列表大小有预算，绘制调用默认≤1000，最终仍受200 IR节点硬上限。
- 独立低权限工作进程，默认墙钟2秒/CPU1秒/内存256MiB；实际内存按运行时启动基线校验。目标Linux/WSL2或已证明等价的Windows Job Object；仅async timeout/单进程内存参数不等于OS资源保护。
- 不继承应用密钥，不开放网络/文件API，工作目录受控；按目标OS证明权限/隔离边界，kill进程组/Job并回收临时文件。不能把AST白名单宣传为任意Python安全执行环境。
- 管理员读取固定审计规则清单，可启禁允许函数、调低限额；expectedRevision保护，硬上限不可放大；每次run存policyRevision/策略快照、源码hash、CPU/墙钟/调用/步骤和终态，生成来源可追溯。

必须验证：合法生成→预览→保存；禁import/属性/I/O；巨量range/深嵌套/大数/超长源；真实CPU/内存压力工作进程熔断（受控测试入口，不对用户开放）；超时后无残留且下一任务可运行；跨用户读404、非管理员改策略403、并发配额、策略冲突409。未触发真实资源边界不能靠预造结果JSON证明保护。

## 6. K1：图谱条件成立就优先做

不要求新建图数据库，接一个明确授权的廉洁文化图谱来源，优先复用合作题目现有服务；读取真实实体ID、属性与一跳关系，映射现有本体/规则。必须取得实际服务/数据、来源说明与调用协议，不能由agent虚构接口。

最小展示：至少3个真实实体、2种关系；相同实体关系/属性变化能影响模板/符号/构图/叙事之一；generation保存来源、外部ID、读取时间、schema/数据版本或内容hash、实体/关系/属性快照与映射依据。旧作品重开不再请求在线图谱；刷新来源创建新generation。

外部超时/无实体/限额反馈明确，不静默回退为站内同名entity。离线缓存可供已抓取快照回放，但要标采集时间/模式；不能把缓存fixture称为实时对接。匿名/作者/审核者的可见性沿现有规则，不把凭据写进快照。

## 7. X：主线通过后的二选一

### X1 LLM 辅助

A服务端调用真实模型，生成IR片段或参数schema提案；B展示预览/校验/修复差异/显式应用。输出先JSON结构校验、IR/参数约束、受限沙盒校验任务，再生成可保存generation。直接IR提案走隔离校验worker，DSL提案走S1解释；未通过不得绕过。

最多一次修复重试，模型超时/拒绝/额度用尽明确提示并保留原作品。至少3个真实自然语言样例与一个非法首次输出修复例；记录模型名、提案hash、修复次数、校验报告（不保存密钥/私密提示）。规则语义生成仍可独立运行。没有真实API不得用mock申报。

### X2 GPU 进阶

基于R2，对现有几何做可展示的批量实例化、一个FBO后处理pass、鼠标交互派生新IR（更新hash再保存），记录FPS/帧时长并按阈值自适应降采样。指标受小场景限制要标明，UI文字不等于实际降采样。后处理参数须入版本快照并纳入复现，不另开第二套不可追溯状态。

仅实现其中一部分就只报告部分覆盖，不自动计满15分。整个X2预算6小时无法实现全部时优先可验证的最小子集；不能挤占F1。
